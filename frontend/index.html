Panduan Singkat

  1. Tempel / unggah file hasil terjemahan (.txt) di panel Editor. Opsional: tempel teks sumber untuk referensi makna.
  2. Buka menu Provider: pilih provider, tambahkan kunci (multi-kunci = load balancing), lalu pilih model.
  3. Kembali ke Editor dan klik Jalankan.
  4. Hasil muncul di tab Hasil / Perubahan / Perlu Dicek. Salin atau unduh .txt.

Instruksi deploy & keamanan ada di GUIDE.md di repo.
