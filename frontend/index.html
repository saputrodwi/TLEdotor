Daftar Provider & Model

load saat pakai

Pilih provider, isi API key di panel Editor, lalu klik Load Models. Di bawah ini ringkasan endpoint & model rekomendasi bawaan.

Panduan Singkat

  1. Tempel / unggah file hasil terjemahan (.txt) di panel kiri. Opsional: tempel sumber bahasa Inggris.
  2. Pilih provider di kanan, tambahkan 1+ API key (multi-key = load balancing otomatis saat limit/rate).
  3. Klik Load Models untuk menarik daftar model provider, lalu pilih model.
  4. Set temperature & max output tokens, lalu ▶ Proses Editor.
  5. Hasil muncul di tab Hasil / Perubahan / Perlu Dicek. Salin atau unduh .txt.

Instruksi detail deploy & keamanan ada di GUIDE.md di repo.

Keamanan API Key

belum dibuka

Key disimpan terenkripsi AES-GCM di perangkat, di-kunci dengan passphrase (PBKDF2). Plaintext hanya ada di memori selama sesi.

Untuk perangkat baru / setelah browser reset, masukkan passphrase yang sama untuk memuat key.

Pemeriksaan Keamanan yang Aktif

    Pengaturan & Koneksi

    Biarkan kosong bila frontend & worker di-host di domain yang sama (deploy Worker + assets). Isi URL worker bila terpisah (Pages + Worker).

    Secret bersama. Worker membandingkan dengan X-TL-Gateway. Jika tidak diisi, request dikirim terbuka (masih tetap rate-limit & HTTPS).

    Aman Kunci API Key

    Passphrase ini dipakai untuk mengenkripsi (AES-GCM) semua API key di perangkat. Tidak bisa dipulihkan bila lupa.

    🛡 Local-only • API key dikirim terenkripsi (TLS) ke Worker TL Editor • Cloudflare Pages + Worker
